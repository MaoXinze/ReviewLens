## 项目背景（30秒）

ReviewLens 是电商品牌评论体验分析平台。技术栈：FastAPI + React 18 + PostgreSQL 16 + Elasticsearch 8 + Redis + MinIO。后端在 `backend/`，基础设施通过 `docker/docker-compose.yml` 启动（分组名 `reviewlens`）。Python/Node 用本地环境。

## 模块定位

本模块为 10 万+ 评论提供全文搜索和聚合分析能力。不新建数据库表，完全基于 Elasticsearch 索引。M2 导入评论时同步写入 ES，本模块提供查询接口。

## 依赖关系

- **上游依赖**：M2（数据导入）— 评论数据已写入 ES 索引

- **上游依赖**：M1（认证）— API 鉴权

- **下游被依赖**：M7（看板）— 聚合数据来源

- **前置条件**：Elasticsearch 8 已启动 + IK 分词器已安装

## 技术设计

### 搜索查询构建

```python
# 关键搜索逻辑
def build_search_query(request: SearchRequest) -> dict:
    must = []
    # 全文搜索（标题+正文，使用 IK 分词）
    if request.query:
        must.append({
            "multi_match": {
                "query": request.query,
                "fields": ["review_title^2", "review_text"],
                "analyzer": "ik_smart"
            }
        })
    # 过滤条件
    filters = []
    if request.filters.dataset_version:
        filters.append({"term": {"dataset_version": request.filters.dataset_version}})
    if request.filters.product_id:
        filters.append({"term": {"product_id": request.filters.product_id}})
    if request.filters.rating_min:
        filters.append({"range": {"rating": {"gte": request.filters.rating_min}}})
    # ... date range, language

    return {"bool": {"must": must, "filter": filters}}
```

### 聚合查询

```python
# 属性差评率聚合
def build_aspect_aggregation(request: AggregateRequest) -> dict:
    return {
        "size": 0,  # 不返回文档，只返回聚合
        "aggs": {
            "aspects": {
                "nested": {"path": "aspects"},
                "aggs": {
                    "aspect_names": {
                        "terms": {"field": "aspects.aspect.keyword", "size": 20},
                        "aggs": {
                            "sentiments": {
                                "terms": {"field": "aspects.sentiment.keyword"},
                                "aggs": {"avg_confidence": {"avg": {"field": "aspects.confidence"}}}
                            }
                        }
                    }
                }
            }
        }
    }
```

## 验收标准

1. 10 万条评论全文搜索 p95 < 500ms
2. 支持中英文混合搜索（如"battery 续航差"）
3. 搜索结果中关键词高亮
4. 聚合查询返回属性差评率排行
5. 筛选条件组合正确（product\_id + rating + date）
6. 分页正确，深翻页不超时
