## 项目背景（30秒）

ReviewLens 是电商品牌评论体验分析平台。技术栈：FastAPI + React 18 + PostgreSQL。

## 模块定位

当属性差评率超过阈值或环比增长异常时自动触发告警，帮助运营在新批次产品出现质量问题后 2 周内发现。同时提供数据导出供离线分析。

## 数据库表

```sql
CREATE TABLE alert_rules (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name            VARCHAR(200) NOT NULL,
    rule_type       VARCHAR(20) NOT NULL,       -- threshold / trend
    aspect          VARCHAR(50) NOT NULL,
    product_id      VARCHAR(100),               -- NULL 表示所有 SKU
    threshold_value FLOAT NOT NULL,             -- threshold: 差评率阈值; trend: 环比增长率
    time_window_days INTEGER NOT NULL DEFAULT 30,
    dedup_days      INTEGER NOT NULL DEFAULT 7,
    status          VARCHAR(20) NOT NULL DEFAULT 'active', -- active/paused
    created_by      UUID NOT NULL REFERENCES users(id),
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE alerts (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    rule_id         UUID NOT NULL REFERENCES alert_rules(id),
    aspect          VARCHAR(50) NOT NULL,
    product_id      VARCHAR(100),
    metric_value    FLOAT NOT NULL,
    trigger_value   FLOAT NOT NULL,
    status          VARCHAR(20) NOT NULL DEFAULT 'active', -- active/acknowledged/resolved
    triggered_at    TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    resolved_at     TIMESTAMPTZ,
    resolved_by     UUID REFERENCES users(id)
);

CREATE INDEX idx_alerts_status ON alerts(status);
CREATE INDEX idx_alerts_rule ON alerts(rule_id);

CREATE TABLE export_records (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    exported_by     UUID NOT NULL REFERENCES users(id),
    dataset_version VARCHAR(100) NOT NULL,
    filters         JSONB NOT NULL,             -- 筛选条件
    file_path       VARCHAR(500) NOT NULL,      -- MinIO 路径
    row_count       INTEGER NOT NULL,
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

## 技术设计

### 告警触发逻辑（定时 ARQ 任务）

```python
async def check_alert_rules(ctx):
    rules = await get_active_rules()
    for rule in rules:
        # 计算当前指标
        current_rate = await get_aspect_negative_rate(
            aspect=rule.aspect, product_id=rule.product_id,
            window_days=rule.time_window_days
        )
        # 去重检查
        if await has_recent_alert(rule, rule.dedup_days):
            continue
        # 判定触发
        if rule.rule_type == 'threshold' and current_rate > rule.threshold_value:
            await create_alert(rule, current_rate, rule.threshold_value)
        elif rule.rule_type == 'trend':
            prev_rate = await get_aspect_negative_rate(
                aspect=rule.aspect, product_id=rule.product_id,
                window_days=rule.time_window_days, offset_days=rule.time_window_days
            )
            growth = (current_rate - prev_rate) / prev_rate if prev_rate > 0 else 0
            if growth > rule.threshold_value:
                await create_alert(rule, current_rate, rule.threshold_value, growth)
```

### 导出逻辑

```python
async def export_reviews(dataset_version, filters, user_id, db, minio_client):
    # 查询评论
    reviews = await search_reviews(db, dataset_version, filters)
    # 生成 CSV
    csv_content = generate_csv(reviews)
    # 上传到 MinIO
    file_path = f"exports/{user_id}/{uuid()}.csv"
    minio_client.put_object("reviewlens", file_path, csv_content)
    # 记录
    await create_export_record(user_id, dataset_version, filters, file_path, len(reviews))
    return file_path
```
