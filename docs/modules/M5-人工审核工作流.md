## 项目背景（30秒）

ReviewLens 是电商品牌评论体验分析平台。技术栈：FastAPI + React 18 + PostgreSQL 16 + Elasticsearch 8。后端在 `backend/`，前端在 `frontend/`。

## 模块定位

本模块通过人工审核提高 NLP 预测标签质量，为模型训练提供可信标注。审核人员逐条确认或修正系统预测的属性和情感标签，审核结果与训练数据严格隔离。

## 依赖关系

- **上游依赖**：M1（认证）、M2（评论数据）、M4（NLP 预测结果）
- **下游被依赖**：M6（训练使用 approved/verified 样本）
- **前置条件**：M4 的批量推理已完成，低置信度样本已生成

## 数据库表

```sql
CREATE TABLE review_tasks (
    id                UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    dataset_version   VARCHAR(100) NOT NULL,
    review_id         VARCHAR(200) NOT NULL,
    sampling_group    VARCHAR(50) NOT NULL,    -- low_confidence / high_risk / random
    sampling_reason   VARCHAR(200),
    -- 系统预测（不可修改）
    system_sentiment   VARCHAR(20),
    system_confidence  FLOAT,
    system_aspects     JSONB,                  -- [{"aspect":"电池续航","sentiment":"negative","confidence":0.82}]
    model_version      VARCHAR(50),
    -- 人工审核
    reviewer_sentiment  VARCHAR(20),           -- positive/neutral/negative
    reviewer_aspects   JSONB,                  -- [{"aspect":"电池续航","sentiment":"negative"}]
    review_reason      VARCHAR(30),            -- confirm_prediction/correct_sentiment/correct_aspects/correct_both/invalid_text/insufficient_info
    review_note        TEXT,
    status             VARCHAR(20) NOT NULL DEFAULT 'pending', -- pending/approved/verified/rejected
    reviewer_id        UUID REFERENCES users(id),
    reviewed_at        TIMESTAMPTZ,
    second_reviewer_id UUID REFERENCES users(id),
    second_reviewed_at TIMESTAMPTZ,
    created_at         TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE(dataset_version, review_id)
);

CREATE INDEX idx_tasks_status ON review_tasks(status);
CREATE INDEX idx_tasks_sampling ON review_tasks(sampling_group, status);

CREATE TABLE review_task_history (
    id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    task_id     UUID NOT NULL REFERENCES review_tasks(id),
    field_name  VARCHAR(50) NOT NULL,
    old_value   TEXT,
    new_value   TEXT,
    changed_by  UUID REFERENCES users(id),
    changed_at  TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    reason      VARCHAR(30)
);

CREATE INDEX idx_history_task ON review_task_history(task_id);
```

## API 端点

| 方法 | 路径 | 说明 | 鉴权 | 角色 |
| --- | --- | --- | --- | --- |
| GET | `/api/v1/review-tasks` | 审核任务列表（按状态/采样组筛选） | 登录 | - |
| GET | `/api/v1/review-tasks/next` | 获取下一条待审核任务（连续审核） | 登录 | operator+ |
| GET | `/api/v1/review-tasks/{id}` | 审核任务详情（含原始评论+系统预测） | 登录 | - |
| PATCH | `/api/v1/review-tasks/{id}` | 提交审核结果 | 登录 | operator+ |
| POST | `/api/v1/review-tasks/{id}/second-review` | 二次复核 | 登录 | analyst+ |
| GET | `/api/v1/review-tasks/summary` | 审核进度统计 | 登录 | - |
| POST | `/api/v1/review-tasks/generate` | 从预测结果生成审核任务 | 登录 | analyst+ |

## 验收标准

1. 可连续审核（调用 /next 获取下一条）
2. 状态机正确流转：pending→approved/verified/rejected
3. approved/verified 可二次复核为 verified
4. 审核历史可追溯"谁、何时、改了什么"
5. summary 返回：总任务数、完成率、一致率
