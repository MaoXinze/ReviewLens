## 项目背景（30秒）

ReviewLens 是电商品牌评论体验分析平台。技术栈：FastAPI + React 18 + PostgreSQL 16 + Elasticsearch 8 + Redis + MinIO。后端在 `backend/`，前端在 `frontend/`，NLP 服务在 `nlp/`。基础设施通过 `docker/docker-compose.yml` 启动（项目分组名 `reviewlens`）。Python/Node 使用本地环境。

## 模块定位

本模块将原始电商评论文件（CSV/JSONL）转换为统一的、版本化的、可追溯的规范化评论数据。它是整个数据流的入口——没有导入就没有搜索、分析和洞察。

## 数据库表

```sql
-- datasets 表
CREATE TABLE datasets (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    dataset_version VARCHAR(100) UNIQUE NOT NULL,  -- ds-{sha256前8位}
    source_filename VARCHAR(255) NOT NULL,
    file_sha256     VARCHAR(64) NOT NULL,
    storage_path    VARCHAR(500) NOT NULL,          -- MinIO 路径
    field_mapping   JSONB NOT NULL,                -- 字段映射记录
    total_rows      INTEGER NOT NULL DEFAULT 0,
    valid_rows     INTEGER NOT NULL DEFAULT 0,
    rejected_rows  INTEGER NOT NULL DEFAULT 0,
    quality_report  JSONB,                         -- 拒绝原因统计
    status          VARCHAR(20) NOT NULL DEFAULT 'pending',  -- pending/importing/completed/failed
    created_by      UUID REFERENCES users(id),
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_datasets_status ON datasets(status);
CREATE INDEX idx_datasets_created ON datasets(created_at);

-- reviews 表（按月分区）
CREATE TABLE reviews (
    id              UUID DEFAULT gen_random_uuid(),
    dataset_version VARCHAR(100) NOT NULL REFERENCES datasets(dataset_version),
    review_id       VARCHAR(200) NOT NULL,
    product_id      VARCHAR(100) NOT NULL,
    product_group_id VARCHAR(100),
    review_title    TEXT,
    review_text     TEXT NOT NULL,
    rating          SMALLINT,                       -- 1-5
    reviewed_at     TIMESTAMPTZ NOT NULL,
    reviewer_id     VARCHAR(200),                   -- 脱敏
    helpful_votes   INTEGER DEFAULT 0,
    verified_purchase BOOLEAN DEFAULT FALSE,
    language        VARCHAR(10) DEFAULT 'en',      -- en/zh/mixed
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    PRIMARY KEY (id, reviewed_at),
    UNIQUE (dataset_version, review_id)
) PARTITION BY RANGE (reviewed_at);

-- 创建默认分区（后续按月自动创建）
CREATE TABLE reviews_default PARTITION OF reviews DEFAULT;

CREATE INDEX idx_reviews_dataset ON reviews(dataset_version);
CREATE INDEX idx_reviews_product ON reviews(product_id);
CREATE INDEX idx_reviews_reviewed ON reviews(reviewed_at);
```

## 技术设计

### 导入流程（异步）

```text
1. POST /datasets/imports 接收文件
2. 计算 SHA-256，检查是否已导入过（幂等）
   → 已存在：返回 reused=true + 原 dataset_version
   → 不存在：存入 MinIO，创建 dataset 记录(status=importing)，提交 ARQ 任务
3. ARQ Worker 异步执行：
   a. 从 MinIO 读取文件
   b. 逐行解析（JSONL 或 CSV）
   c. 校验每行（见校验规则）
   d. 批量写入 PostgreSQL（每 1000 行一批）
   e. 同步写入 Elasticsearch（每 1000 条一批）
   f. 生成质量报告
   g. 更新 dataset.status = completed
   h. 失败时更新 status=failed + error_message
4. 前端轮询 GET /datasets/{version} 查看状态
```

### 校验规则

| # | 规则 | 失败处理 |
| --- | --- | --- |
| 1 | 文件不能为空 | 拒绝导入 |
| 2 | 必填：review_id, product_id, review_text, reviewed_at | 记入拒绝报告 |
| 3 | review_id 同一数据集内唯一 | 重复行记入拒绝 |
| 4 | review_text 非空，长度 1-5000 | 空或超长记入拒绝 |
| 5 | reviewed_at 可解析为时间戳 | 格式错误记入拒绝 |
| 6 | rating 如存在，为 1-5 整数 | 非法值记入拒绝 |
| 7 | 识别语言标记（en/zh/mixed） | 记录在规范化结果 |

### Elasticsearch 索引同步

导入完成后，评论同步写入 ES 索引 `reviews`，映射见架构设计文档 §6.2。

### 版本号生成

```python
import hashlib

def generate_dataset_version(file_content: bytes, field_mapping: dict) -> str:
    sha = hashlib.sha256(file_content).hexdigest()[:8]
    return f"ds-{sha}"
```

## 验收标准

1. 上传 10 条 JSONL 文件，3 秒内完成导入，返回 dataset_version
2. 上传含 2 条无效数据的文件，有效行进入版本，拒绝行在质量报告中
3. 重复上传同一文件，返回 `reused=true` + 原 dataset_version
4. 导入完成后 Elasticsearch 可搜索到评论
5. 支持中文评论的导入和 ES 索引
6. 异步任务失败时 status=failed + 有错误信息
