## 项目背景（30秒）

ReviewLens 是电商品牌评论体验分析平台。技术栈：FastAPI + React 18 + PostgreSQL。后端在 `backend/`。

## 模块定位

将分析洞察转化为可追踪、可验证的改进行动。问题卡从看板创建，分派给研发，处置后验证，关闭后回测效果。是"分析→行动"闭环的核心。

## 数据库表

```sql
CREATE TABLE issues (
    id                UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    dataset_version   VARCHAR(100) NOT NULL,
    title             VARCHAR(200) NOT NULL,
    aspect            VARCHAR(50) NOT NULL,       -- 受控词表
    severity          VARCHAR(20) NOT NULL,       -- low/medium/high/critical
    status            VARCHAR(30) NOT NULL DEFAULT 'open', -- open/in_progress/pending_validation/closed
    description       TEXT,
    source_review_ids JSONB NOT NULL,            -- ["R123","R456",...]
    assignee          UUID REFERENCES users(id),
    resolution_note   TEXT,
    validation_note   TEXT,
    created_by        UUID NOT NULL REFERENCES users(id),
    updated_at        TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    closed_at         TIMESTAMPTZ
);

CREATE INDEX idx_issues_status ON issues(status);
CREATE INDEX idx_issues_aspect ON issues(aspect);
CREATE INDEX idx_issues_assignee ON issues(assignee);

CREATE TABLE issue_history (
    id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    issue_id    UUID NOT NULL REFERENCES issues(id),
    field_name  VARCHAR(50) NOT NULL,           -- status/assignee/severity/...
    old_value   TEXT,
    new_value   TEXT,
    changed_by  UUID NOT NULL REFERENCES users(id),
    changed_at  TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    reason      TEXT
);

CREATE INDEX idx_history_issue ON issue_history(issue_id, changed_at);
```

### 状态机

```text
open → in_progress (填写处置说明)
in_progress → open (退回)
in_progress → pending_validation (处置完成)
pending_validation → in_progress (验证失败退回)
pending_validation → closed (必须填写验证结论，终态)
```

### 效果回测

```python
async def retrospect_issue(issue_id, db):
    issue = await get_issue(issue_id)
    # 获取创建时的差评率
    pre_rate = await get_aspect_negative_rate(
        dataset_version=issue.dataset_version,
        aspect=issue.aspect,
        end_date=issue.created_at
    )
    # 获取最新的差评率
    latest_dataset = await get_latest_dataset()
    post_rate = await get_aspect_negative_rate(
        dataset_version=latest_dataset.version,
        aspect=issue.aspect,
        start_date=issue.created_at
    )
    return {
        "pre_rate": pre_rate,
        "post_rate": post_rate,
        "change": post_rate - pre_rate,
        "improved": post_rate < pre_rate
    }
```

## 验收标准

1. 不能跳过 pending_validation 直接关闭
2. 来源评论必须属于问题卡的 dataset_version
3. 状态变更记录审计轨迹（操作者+前后值+时间）
4. 关闭后回测显示创建前后差评率对比
5. closed 为终态不可流转
