# M11 模型增强实验（P7 阶段）

> 状态：设计完成，待实施（依赖 P6 真实数据闭环完成）
> 前置模块：M4 NLP 管线（TF-IDF+LR 基线）、M6 模型训练与评测（训练运行记录）

## 项目背景（30 秒）

ReviewLens 是面向电商品牌运营的评论体验分析平台。M4 已实现 TF-IDF+LR
情感三分类基线，M6 实现了训练运行记录与发布门槛。本模块把"一个基线模型"
升级为"完整的模型选型与成本论证实验"：

- **基线常驻**：TF-IDF+LR（低延迟、可解释、零成本）
- **增强层**：DistilBERT 微调（垂类精度提升，CPU 可训练）
- **论证层**：LLM 蒸馏对照（可选，需 API 预算确认）

产出面试核心故事：弱标签 vs 蒸馏、基线 vs 微调、成本-精度权衡分析。

## 为什么是 DistilBERT

| 维度 | DistilBERT-base-uncased | 备注 |
| --- | --- | --- |
| 参数量 | 6600 万 | CPU 可训练（小时级） |
| 英文支持 | 原生 | Amazon Reviews 是英文数据 |
| 与基线可比 | 同数据同标签同切分 | 公平对比的前提 |
| 推理成本 | 约为基线的 40 倍 | 分层推理的动机 |

## 三层架构设计

```text
第一层（生产）：TF-IDF+LR 基线常驻
  ↳ 小数据低延迟可解释，P6 已完成闭环

第二层（增强）：DistilBERT 微调
  ↳ 样本量敏感性实验：1k / 5k / 2万 / 5万 各训一次
  ↳ 产出"样本量-性能曲线"，确定深度模型收益拐点

第三层（论证）：LLM 蒸馏对照实验（可选）
  ↳ 大模型 API 抽样标注 2000-5000 条（高质量软标签）
  ↳ 对比三条路线：A 弱标签基线 / B 纯弱标签微调 / C LLM蒸馏微调
  ↳ 产出成本-精度权衡分析
```

| 实验 ID | 训练数据 | 模型 | 样本量 | 记录指标 |

统一约束：同一份测试集（分层抽样 20%）、固定 random_seed=42，
保证跨实验可比。

## 分层推理策略

```text
新评论 → 基线预测
  ├── confidence ≥ θ_high（如 0.90）→ 直接采用（约 70-80% 流量）
  └── confidence <  θ_high → 送 DistilBERT 复核（约 20-30% 流量）
```

产出指标：分流比例、复核前后 F1 差值、平均时延。
这是企业真实做法（cascade inference），不是为炫技。

## 风险与对策

| 风险 | 对策 |
| --- | --- |
| CPU 训练 5 万样本过慢 | 用小 batch + early stopping；或先用 2 万验证流程 |
| transformers 依赖破坏现有环境 | 独立 requirements 段落，装前 dry-run 解析验证 |
| LLM API 需要预算 | E2 标记可选，用户确认后才启动 |
| 微调后 F1 提升不显著 | 这本身是有效结论，如实写进报告（负结果也有价值） |
