## 项目背景（30秒）

ReviewLens 是电商品牌评论体验分析平台。技术栈：FastAPI + React + PostgreSQL + Elasticsearch + MinIO。NLP 服务在 `nlp/`，后端在 `backend/`。

## 模块定位

本模块管理模型训练的编排、评测指标记录、发布门槛判定和版本回滚。NLP 服务（M4）执行实际训练，本模块管理训练的生命周期和发布决策。

**与 M4 的边界**：M4 是 NLP 计算引擎（预处理、抽取、分类、训练执行），M6 是后端模型管理层（编排、评测指标展示、发布/回滚状态机）。

## 依赖关系

- **上游依赖**：M1（认证）、M4（NLP 服务可训练）、M5（approved/verified 审核样本）
- **下游被依赖**：M4（published 模型作为生产推理模型）、M7（看板标注模型版本）
- **前置条件**：M5 有 >= 200 条 approved/verified 样本

## 发布门槛逻辑

```python
def check_publish_criteria(run: AnalysisRun) -> tuple[bool, str]:
    if run.macro_f1 is None or run.macro_f1 < 0.70:
        return False, f"Macro-F1 {run.macro_f1} < 0.70"
    if run.test_samples < 1000:
        return False, f"测试样本 {run.test_samples} < 1000"
    # 检查审核覆盖率
    coverage = calculate_review_coverage(run.dataset_version)
    if coverage < 0.80:
        return False, f"审核覆盖率 {coverage:.0%} < 80%"
    return True, "发布条件满足"
```

## 验收标准

1. 训练只用 approved/verified 样本，pending/rejected 不可进入训练
2. 指标低于门槛时不可发布（返回具体原因）
3. 发布后新推理使用新模型，旧模型 archived
4. 回滚后推理使用上一版本
5. 训练产物可复现（相同数据+seed=42 → 相同指标）
