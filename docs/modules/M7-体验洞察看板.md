## 项目背景（30秒）

ReviewLens 是电商品牌评论体验分析平台。技术栈：FastAPI + React 18 + PostgreSQL + Elasticsearch 8。前端用 Ant Design 5 + @ant-design/charts。

## 模块定位

让运营在 3 分钟内定位当前最严重的体验问题。聚合 NLP 预测结果为属性差评率排行、趋势时间序列、SKU 对比，每个数字可下钻到证据评论。

## 依赖关系

- **上游依赖**：M1（认证）、M3（ES 搜索聚合）、M4（NLP 预测结果已入库+入ES）
- **下游被依赖**：M8（问题卡从看板洞察创建）
- **前置条件**：M4 批量推理已完成，ES 中有 aspects 字段

## API 端点

## 技术设计

### 聚合查询核心

```python
# 属性差评率排行（基于 ES nested 聚合）
async def get_aspect_ranking(dataset_version, product_id=None, period=None):
    body = {
        "size": 0,
        "query": {"bool": {"filter": build_filters(dataset_version, product_id, period)}},
        "aggs": {
            "aspects": {
                "nested": {"path": "aspects"},
                "aggs": {
                    "names": {
                        "terms": {"field": "aspects.aspect", "size": 12},
                        "aggs": {
                            "sentiments": {"terms": {"field": "aspects.sentiment"}},
                            "neg_rate": {
                                "bucket_script": {
                                    "buckets_path": {"neg": "sentiments[negative]->_count", "total": "_count"},
                                    "script": "params.neg / params.total"
                                }
                            }
                        }
                    }
                }
            }
        }
    }
```

### 证据下钻

每个聚合数字附带一个 `evidence_query`，前端点击时用该查询调 `/insights/evidence` 接口获取原始评论。

## 验收标准

1. 属性排行数字 = 下钻评论数之和
2. 环比变化使用上一同等时间窗口对比
3. 每个聚合数字附带 model_version + dataset_version
4. 总览看板加载 < 2 秒
5. 趋势图支持周/月粒度切换
