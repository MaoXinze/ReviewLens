## 项目背景（30秒）

ReviewLens 是电商品牌评论体验分析平台。技术栈：FastAPI + React 18 + PostgreSQL 16 + Elasticsearch 8 + Redis + MinIO。基础设施通过 Docker Compose 管理（分组名 `reviewlens`），Python/Node 用本地环境。

## 模块定位

提供一键启动的基础设施、CI/CD 流水线、测试框架和项目脚手架。贯穿所有阶段，是其他模块的前提和交付保障。

### Makefile 常用命令

```makefile
.PHONY: up down logs init backend nlp frontend test lint

# 基础设施
up:       ## 启动 Docker Compose 基础设施
	docker compose -f docker/docker-compose.yml up -d
down:     ## 停止基础设施
	docker compose -f docker/docker-compose.yml down
logs:     ## 查看基础设施日志
	docker compose -f docker/docker-compose.yml logs -f
init:     ## 初始化（启动基础设施 + 建库 + 建 ES 索引）
	docker compose -f docker/docker-compose.yml up -d
	python scripts/init_db.py
	python scripts/init_es_index.py

# 服务
backend:  ## 启动后端开发服务器
	cd backend && uvicorn app.main:app --reload --port 8000
nlp:      ## 启动 NLP 服务
	cd nlp && uvicorn app.main:app --reload --port 8100
frontend: ## 启动前端开发服务器
	cd frontend && npm run dev
worker:   ## 启动 ARQ worker
	cd backend && python -m app.worker

# 测试
test:     ## 运行全部测试
	cd backend && pytest
	cd nlp && pytest
	cd frontend && npm test
lint:     ## 代码检查
	cd backend && ruff check .
	cd frontend && npx tsc --noEmit
```

### CI/CD 流水线

```yaml
# .github/workflows/ci.yml
name: CI
on: [push, pull_request]
jobs:
  backend-test:
    runs-on: ubuntu-latest
    services:
      postgres:
        image: pgvector/pgvector:pg16
        env: { POSTGRES_DB: test, POSTGRES_USER: test, POSTGRES_PASSWORD: test }
        ports: ["5432:5432"]
      redis:
        image: redis:7.2
        ports: ["6379:6379"]
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: "3.12" }
      - run: pip install -r backend/requirements.txt -r backend/requirements-dev.txt
      - run: cd backend && pytest --cov=app --cov-report=xml
      - run: cd nlp && pip install -r requirements.txt && pytest

  frontend-build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: "22" }
      - run: cd frontend && npm ci && npm run build && npx tsc --noEmit
```

## 验收标准

1. `docker compose -f docker/docker-compose.yml up -d` 一键启动 4 个容器
2. ES 启动后 IK 分词器可用（`_analyze` 接口测试中文分词）
3. `make init` 完成数据库迁移 + ES 索引创建
4. `make backend` + `make frontend` + `make nlp` 三个服务可同时运行
5. CI 在 GitHub push 后自动运行测试
6. 新人 clone 后按 README 步骤 10 分钟内跑起来
