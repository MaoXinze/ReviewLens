## 2. 样本量-性能曲线（E1）

```
Macro-F1
0.70 ┤                                    ●0.6786      ●0.6468
0.65 ┤
0.60 ┤          ●0.5682          ●0.5876
0.55 ┤
     └─────────────────────────────────────────────────────────► 样本量
        1,000      5,000      20,000     29,904
```

**结论（收益拐点在 2 万左右）**：

- 1k→20k：Macro-F1 从 0.568 → 0.679，随数据量近似单调上升，20k 是明显收益拐点；

- 20k→29.9k：F1 反而略降（0.679→0.647），Accuracy 基本持平（0.9045→0.9049）。
  —— **这是有效的负结果**：弱标签下标注质量同质，继续加量已无增益，甚至引入噪声。

- 决策：**深度模型取 20k 训练产物作为生产候选（`distilbert_exp_20000`）**，不必堆到 5 万。

## 3. 分层推理（cascade）权衡曲线

固定持出测试集 2,000 条（位置 \[20000,22000)，20k 模型从未见过）；深度层取 `distilbert_exp_20000`。

| θ          | Macro-F1   | Accuracy | 基线流量      | 深度流量  |
| ---------- | ---------- | -------- | --------- | ----- |
| 仅基线        | 0.5489     | 0.7040   | 100%      | 0%    |
| 深度全量       | 0.6449     | 0.9095   | 0%        | 100%  |
| **θ=0.60** | **0.6602** | 0.8785   | **53.5%** | 46.5% |
| θ=0.70     | 0.6478     | 0.8980   | 40.3%     | 59.7% |
| θ=0.80     | 0.6486     | 0.9080   | 28.2%     | 71.8% |
| θ=0.90     | 0.6449     | 0.9095   | 17.1%     | 82.9% |
| θ=0.95     | 0.6449     | 0.9095   | 10.0%     | 90.0% |

**原始观察**：TF-IDF+LR 的三分类软化概率普遍偏低，θ 取高（0.90+）会让绝大多数流量进深度模型，失去分层省算力的意义。

**结论（有几个反直觉但真实发现）**：

1. **cascade 可反超深度全量**：θ=0.60 时 Macro-F1=0.660 > 深度全量 0.645。LR 在高置信段（≥0.60）预测可靠，把这些样本留在基线，把不确定样本交给深度模型，反而整体更稳。
2. **真正的成本-精度最优点是 θ≈0.70**：F1=0.6478 与深度全量几乎持平，但只把 \~60% 流量送深度——即省 **\~40% 深度推理算力**而精度零损耗。
3. Accuracy 与 Macro-F1 出现背离（θ 越低 Acc 越低、F1 反而高）：高 θ 时深度模型强化了对多数类（正向）的判断，牺牲了少数类召回。

## 4. 成本与算力分析

| 维度           | 第一层 TF-IDF+LR | 第二层 DistilBERT    |
| ------------ | ------------- | ----------------- |
| 参数量          | 约 5 万特征权重     | 66M               |
| 训练（20k）      | 秒级            | 176.3s（单卡 GPU）    |
| 推理单位成本       | 近 0           | 约为基线的几十倍          |
| 延迟           | 微秒级           | 毫秒级（tokenize+前向）  |
| 可解释性         | 特征权重可解释       | 黑盒                |
| 分层组合（θ=0.70） | 承担 40%        | 承担 60% → F1 与全量持平 |

**成本故事**：分层推理不是"堆算力"，而是**在 F1≈0.648 前提下把 40% 流量留在零成本基线**；
若取 θ=0.60 则整体 F1 提升到 0.660（略优于深度全量），同时仍省 53.5% 的计算。精度、成本、延迟三者在此策略下形成可数据回退的权衡。

## 5. 三线对比（面试核心故事）

| 路线           | 训练数据                         | 模型         | F1                          | 成本             | 结论                 |
| ------------ | ---------------------------- | ---------- | --------------------------- | -------------- | ------------------ |
| A 弱标签基线      | 评分弱标签 2万                     | TF-IDF+LR  | 0.549（持出集）                  | 极低             | 快速上线兜底             |
| B 弱标签微调      | 评分弱标签 2万                     | DistilBERT | 0.679（20k 内部）               | 中              | 精度提升 21%（相对基线）     |
| C 弱标签微调+分层   | 同上                           | B + 分层推理   | 0.660（持出集, θ=0.60）          | 中但与 A 共享 53.5% | 成本-精度最优            |
| D LLM 蒸馏标签微调 | qwen3.7-max / deepseek 标签 4k | DistilBERT | **0.786 / 0.746（固定 1k 持出）** | 中 + 少量 LLM API | 弱标签瓶颈已明确；qwen 标签最佳 |

## E2. LLM 蒸馏对照（qwen3.7-max 标签 vs 弱标签）

固定切分：同 5k 条（全局 shuffle\[0:5000]，seed=42），train=`[0:4000]`，持出 test=`[4000:5000]`（1,000 条，两路模型均未见）。唯一变量 = 标签来源。

| 标签来源                    | 训练样本  | 测试样本  | Macro-F1   | Accuracy | 分歧率    |
| ----------------------- | ----- | ----- | ---------- | -------- | ------ |
| 弱标签（评分折算）               | 4,000 | 1,000 | 0.5969     | 0.9100   | —      |
| LLM 标签（qwen3.7-max）     | 4,000 | 1,000 | **0.7857** | 0.8930   | 12.16% |
| LLM 标签（deepseek-v4-pro） | 4,000 | 1,000 | 0.7460     | 0.8490   | 17.12% |

**结论（关键正结果）**：

- **LLM 高质量标签将 Macro-F1 显著提升**：qwen3.7-max +0.1887（0.597→0.786，相对 +31.6%）；deepseek-v4-pro +0.1494（0.597→0.746，相对 +25.0%）。在相同模型、相同数据、相同切分下，仅换标签来源即获显著增益，**证明弱标签（评分折算）正是提升瓶颈**。

- **qwen3.7-max 标签质量 > deepseek-v4-pro**：两种 LLM 均远超弱标签，但 qwen 的 F1 高出 deepseek 0.040（0.786 vs 0.746）。deepseek 分歧率更高（17.12% vs 12.16%）且 Acc 偏低——它对 minority 类判罚更激进/noisy，标签质量略逊，故蒸馏效益次之。

- 三路共享同一持出测试（test=\[4000:5000]，两路弱标签 F1 均 ≈0.597 复现一致），对照干净可信。

- **生产启示**：优先用 qwen3.7-max 做 LLM 蒸馏标签 + DistilBERT 微调（best F1=0.786）；deepseek-v4-pro 也很可用（0.746）。因 100 万 token 免费额度可覆盖约 5–8k 评论标注，建议对线上低置信样本增量打标迭代（飞轮），配合 §3 的分层推理在保证精度的同时控制深度调用成本。
